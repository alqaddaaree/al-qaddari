#### 1\. Create a New Paragraph Style

  * Press `F11`
  * Open `Paragraph Styles`
  * Right click any style
  * Press `New`
  * Name it:


    
    
    Telegram Quote

#### 2\. Configure Indentation

Go to:
    
    
    Indents & Spacing

Use:

  * Left: `0.80 cm`
  * Right: `0.80 cm`
  * Above paragraph: `0.20 cm`
  * Below paragraph: `0.20 cm`
  * First line: `0.00 cm`



#### 3\. Add Edge Borders

Go to:
    
    
    Borders

Enable only:

  * Left border
  * Right border



Recommended:

  * 0.75pt line
  * Soft gray color



You may customize that. 

Using both borders keeps the block visually correct in both:

  * English
  * Arabic



A single left border does not mirror properly in RTL text.

#### 4\. Add Background Color

Go to:
    
    
    Area -> Color

Choose:

  * Very light gray
  * Or slightly tinted background



The goal is subtle contrast, not a solid box.

#### 5\. Optional Font Adjustment

Go to:
    
    
    Font

Recommended:

  * Main text: `12 pt`
  * Quote block: `11 pt`



#### 6\. Save and Reuse

Press `OK`.

To use it later:

  * Highlight text
  * Double-click the style



Done.

Works well for:

  * quotations
  * translated excerpts
  * commentary blocks
  * research notes
  * Arabic + English mixed documents
